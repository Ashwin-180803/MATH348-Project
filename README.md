# How to Run(For developers)
1. Download the mathsite folder as zip/ Pull the github repository to your local machine
2. Open the foolder in any of your desired Code-interpreter
3. Install the requirements (Make a new python Virtual environment for easier file handling)
4. Run the command "venv\Scripts\activate" (If virtual environment not yet activated)
5. Run the command "python manage.py runserver" to run the server locally
6. Access the server from any browser at "http://127.0.0.1:8000/"
